# UNAV Pro — First Run Guide

Your first ten minutes with the v3.5 public alpha.

For the wider testing context see
[`PUBLIC_ALPHA_TESTING_GUIDE.md`](PUBLIC_ALPHA_TESTING_GUIDE.md).
For install-only steps see
[`INSTALL_C4D_2023_PLUS.md`](INSTALL_C4D_2023_PLUS.md).

---

## 1. After install

1. Quit Cinema 4D if it's open.
2. Unzip the v3.5 release into the Cinema 4D
   plug-ins folder.
3. Restart Cinema 4D.
4. `Extensions → Universal Navigator Pro` opens the
   dialog.

The status log's first line shows the version. If it
says `UNAV Pro v3.5.0 (Public Alpha…)`, the install
succeeded.

## 2. The welcome banner

On first open the dialog shows a *Welcome* banner
generated by `core/first_run.py`. The banner picks
one of five "next step" recommendations based on
what's already loaded:

| Stage | What you see |
| --- | --- |
| `no_workspace` | "Open a workspace" + suggested action |
| `no_datasets` | "Add a dataset" |
| `no_navigator` | "Create a navigator" |
| `no_visible_sector` | "Sync the visible sector" |
| `ready` | "Ready" — you're all set |

The same recommendation appears in the *Welcome* tab
plus, briefly, in the status log so you don't have
to dig.

## 3. Step 1 — Open the bundled workspace

The fastest start: open the `internal_beta_demo`
workspace bundled inside the release zip.

> `Project → Open Workspace…` →
> `samples/internal_beta_demo/`

The workspace contains:

* Two synthetic demo datasets (5 Gaia-style stars +
  3 JPL-style bodies).
* A three-stop demo mission.
* A three-stop demo route.
* A three-step demo presentation.
* A project notes file.

After loading, the *Project Summary* line should
read something like:

```
Project: UNAV Internal Beta Demo
Datasets: 2 enabled / 2 total
Missions: 1
Routes:   1
Timelines: 0
Notes:    1
```

## 4. Step 2 — Run the health check

> `Diagnostics → Run Health Check`

You should see 14 probes, all `[OK]` or `[..]`
(info). No `[ERR]`. If a probe errors:

1. Click `Diagnostics → Create Issue Report`.
2. File a bug — see
   [`ISSUE_REPORTING.md`](ISSUE_REPORTING.md).

## 5. Step 3 — Sync the visible sector

> `Sync Visible Sector`

The status log reports:

```
Sync: +N added, =M kept, -K removed (mode=…)
```

Cinema 4D's Object Manager now contains:

```
UNAV_Project
├── UNAV_Navigation
│   └── UNAV_Navigator
├── UNAV_VisibleSector
│   └── UNAV_Object_<uid> × N
├── UNAV_Overlays
├── UNAV_ScienceLayers
├── UNAV_Missions
└── UNAV_Debug
```

If you re-click *Sync Visible Sector* without
moving the navigator, the status reads
`unchanged (N visible)` — that's the v3.0
short-circuit.

## 6. Step 4 — Inspect a starfield child

Click any `UNAV_Object_*` child in the OM, then:

> `Inspect Selected Object`

The metadata panel shows:

* The v1.3 nine-section summary (identity / position /
  motion / photometry / classification / derived /
  summary / glossary / interpretation).
* The v3.2 *Provenance* block (catalog source +
  connector + units + known limitations).
* The v3.2 *Data integrity findings* block (any
  warnings / errors the v3.2 audit caught for this
  row).

## 7. Step 5 — Run the demo presentation

> `Presentation → Open Presentation…` →
> *UNAV Internal Beta Talk*
> → `Start Presentation`

The dialog walks you through three steps:

1. Pleiades Star — overlays for distance rings +
   galactic plane.
2. Earth — the JPL ephemeris row at the demo epoch.
3. Mars — same epoch; note the parallax shift.

Use *Next Step* / *Previous Step* / *Pause* /
*Resume*. Presenter notes appear in the side panel.

## 8. Step 6 — Bake + export

If you want to confirm the timeline + export paths:

1. `Bake to Timeline` against the demo mission.
   Status reports the frame count, waypoint count,
   and marker count.
2. Scrub the timeline to confirm the camera moves.
3. `Export → Export Full Package…` to
   `<workspace>/exports/`. The `manifest.json`
   carries v3.2 self-describing fields
   (`provenance_summary`, `audit_summary`,
   `coordinate_conventions`, `known_limitations`).

## 9. "No data loaded yet" hints

Several panels show the v3.5 *empty-state hint*:

> No data loaded yet. Run Diagnostics → Run Health
> Check to confirm the install is healthy, or follow
> the next-step recommendation above.

This is the same message everywhere; if you see
something different, file a docs bug.

## 10. Common first-run hiccups

* **The dialog doesn't appear.** Confirm the plug-in
  path; see
  [`INSTALL_C4D_2023_PLUS.md`](INSTALL_C4D_2023_PLUS.md).
  Run `python scripts/run_tests.py --quiet` from a
  terminal to confirm the package itself is healthy.
* **Health check reports `[ERR]`.** Run *Create
  Issue Report*. File a bug.
* **The bundled workspace won't open.** Confirm
  the workspace root has all eight subdirectories;
  v3.4 ships every directory pre-created (some are
  empty). Use *Diagnostics → Reset → Rebuild Scene
  Hierarchy* if the on-disk tree was edited
  externally.
* **Sync produces zero objects.** Check the
  navigator's `cone_angle_deg` + `far_clip_parsec`.
  Default 30° / 500 pc covers the bundled demo.
